# Vupai downloads

Installers and signed updates for **Vupai Community**, the free workspace for coding agents.

[Website](https://vupai.dev) · [Releases](https://github.com/itsjrsa/vupai-releases/releases)

Downloads are being validated privately. Public downloads are not available yet.
This repository contains distribution files, not application source code.
The app includes its license and third-party notices.

The `channels` branch holds the Community beta feed. Versioned installers and
update packages are attached to releases; old releases are retained.
