# Installation and update help

For download, installation or update problems, open an
[issue in this repository](https://github.com/itsjrsa/vupai-releases/issues/new).
Existing testers may continue using their current feedback channel.

Include:

- The Vupai version from **About & support**, or the installer filename if the
  app does not open.
- Your macOS version and Mac model/chip.
- Whether this was a first installation, a manual upgrade or an in-app update.
- The steps you took, the exact error and what you expected to happen.

For an update problem, say whether it happened while checking, downloading,
verifying, installing or restarting. A screenshot of the error can help.
Remove credentials, private project details and personal information from anything
you share. This repository's issues will be public when public downloads launch.

## Common situations

**There are no downloads yet.** The first public release is still being prepared.
The repository's Releases page will list installers when they are available.

**My existing app does not offer in-app updates.** Older builds need one manual
installation of an updater-enabled DMG. That bootstrap release has not been
published here yet.

**An update download failed.** Your panes keep running. Retry when the connection
is available; the app verifies the download before making installation available.

**Installation failed.** Follow the app's error message. A recoverable failure
keeps the verified download ready to retry. If the installed app cannot be
verified, the message identifies a saved copy for recovery. Do not discard that
copy before the app is working again.

**I have running panes.** An update waits for your restart decision. Restarting
ends active local pane processes across projects; workspace resume does not keep
those processes alive. Save your work before confirming.
